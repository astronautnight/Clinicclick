# **App Name**: Clinic@Click

## Core Features:

- Full Feature Set: Dental patient management software with homepage as dashboard view of all tabs. Top right icon is a profile page for an individual or clinic (editable and deletable). Add new patient data (dental data, photos, videos). Doctors tab for assigning patients/procedures. Appointment reminders. Regularly used procedures (basic + ability to add more, with templates) linked to patients. List of generic dental drugs (tablets, toothpastes, mouthwashes) documented as part of clinic data; share prescriptions. Track earnings/expenses in rupees (daily, weekly, monthly) with basic dental clinic data. Easily share patient case details. Send standardized WhatsApp messages. Doctor/clinic profile page. Real-time patient communication dashboard. Interactive dental education module. Professional font & CC for logo. Google Drive backup. Upload dental educational videos. Interactive UI with icons. Optimized contents for tabs. Mobile web view compatible. Dark mode. Colorful tabs with icons.
- Centralized Dashboard: Dashboard with quick access to patient data, appointment scheduling, and financial overview.
- Patient Records: Patient profile management for storing patient details, treatment history, and dental records.
- Appointment Reminders: Appointment reminders via WhatsApp messages.

## Style Guidelines:

- Primary color: Light teal (#A0E7E5) for a clean and professional look.
- Secondary color: Soft gray (#F2F4F4) for backgrounds and content separation.
- Accent: Coral (#FFAEBC) for interactive elements and highlights.
- Professional and readable font for all text elements.
- Use a consistent set of line icons for dashboard tabs and UI elements.
- Responsive layout for compatibility across devices.
- Card-based layout for displaying information in an organized manner.
- Subtle transitions and animations to enhance user experience.
- Dark mode: Dark gray (#333333) background with light text for comfortable viewing in low-light conditions.
